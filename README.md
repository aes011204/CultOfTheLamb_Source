# Cult of the Lamb — 모작 프로젝트

C++ / DirectX 9로 구현한 4인 팀 프로젝트입니다.
게임 리소스를 제외한 전체 소스 코드를 공개합니다.

## 담당 파트

### 보스 전투

- 보스 1페이즈와 중간보스의 상태 머신 및 행동 전환 처리
- 탄막·사슬 공격과 근접 공격·소환 등 보스별 패턴 구현
- 공격 경고 표시, 애니메이션 및 공격 타이밍 연동

### 인벤토리와 아이템

- 슬롯 기반 아이템 추가·제거·수량 관리 및 아이템 획득 처리
- 월드 아이템 드롭, 인벤토리 아이템 드롭 및 획득 알림 연동
- 상자와 드롭 아이템의 연출 및 관련 오류 수정

### 채집과 상호작용

- 나무·바위·채집물의 접근 감지, 피격 반응 및 채집 처리
- 피킹·호버링·외곽선 표시를 통한 상호작용 대상 표현
- 채집 결과에 따른 아이템 드롭 연동

### 요리 시스템

- 보유 재료 확인, 레시피 선택 및 요리 대기열 관리
- 요리 시작·취소와 결과물 생성 처리
- 요리 미니게임 UI·입력 처리 및 인벤토리·드롭 시스템 연동

### 이펙트와 메인 메뉴

- 스프라이트 이펙트와 이동 궤적을 표현하는 트레일 이펙트 구현
- 트레일의 수명·폭·카메라 방향 처리 및 렌더 상태 충돌 수정
- 메인 메뉴 화면과 메뉴 요소 구현

## 참고

학습 및 포트폴리오용 모작 프로젝트입니다. 게임 리소스와 빌드 결과물은 포함하지 않습니다.
원작의 명칭과 리소스, 외부 라이브러리의 권리는 각 권리자에게 있습니다.
